# Indian Population Analysis

## Project Overview

This project analyzes district-level Indian population data using Python. The analysis focuses on population statistics, state-wise population distribution, gender distribution, filtering, data validation, and visualization.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib

## Dataset

The dataset contains 600 district-level records with demographic information such as:

- State
- District
- Population
- Male Population
- Female Population
- Literacy Rate

## Analysis Performed

- Inspected the dataset using Pandas
- Calculated total, average, maximum, and minimum population
- Identified the top 10 districts by population
- Identified the district with the highest population
- Filtered districts with population greater than 100,000
- Filtered districts with population greater than 100,000 and literacy rate greater than 90%
- Calculated state-wise total population using `groupby()`
- Identified the highest-population state
- Identified the top 10 states by total population
- Analyzed total male and female population
- Calculated male and female population percentages
- Used NumPy for numerical calculations
- Performed data validation by comparing population totals
- Created visualizations using Matplotlib

## Key Findings

- The dataset contains 600 district-level records.
- Total population in the dataset is 39,495,789.
- Uttar Pradesh has the highest state-level population in the dataset with 2,171,798.
- 46 districts have a population greater than 100,000.
- 4 districts have both a population greater than 100,000 and a literacy rate greater than 90%.
- Male population: 20,418,272 (approximately 51.69%).
- Female population: 19,077,517 (approximately 48.31%).

## Conclusion

This project demonstrates how Python can be used to analyze raw population data, perform calculations and aggregations, validate results, and communicate insights through data visualization.

The project helped strengthen practical skills in Pandas, NumPy, Matplotlib, data analysis, and data visualization.
